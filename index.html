거래·비용 설정

0.45를 45%로 해석하지 않습니다. 목표 현금비중은 0 이상 100 이하의 퍼센트 숫자로만 입력합니다.

월간 운영 안내

1. 매월 정해진 하루에 현재 달러 현금, 현금성 자산, QQQ 수량, QQQ 기준가격을 입력합니다.
2. 목표 현금비중은 사용자가 정하는 입력값입니다. 45%는 예시일 뿐 추천값이 아닙니다.
3. 결과를 확인한 뒤 실제 주문은 사용자가 증권사에서 직접 실행합니다.
4. 체결 후 실제 체결가격과 수량으로 다시 계산해 비중을 확인합니다.
